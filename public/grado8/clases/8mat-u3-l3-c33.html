3.3 Aplicaciones de la función lineal, parte 3

Unidad 3 • Lección 3 • Matemática 8°

Problema Inicial

En el rectángulo ABCD, el punto E se mueve sobre el borde del rectángulo desde el punto A, hasta D, pasando por los puntos B y C. Cuando el punto E se ha movido $x \text{ cm}$, se toma el área del triángulo AED como $y \text{ cm}^2$. Observa las figuras y responde:

Figura 2
Figura 3

1. Explica qué sucede con el área del triángulo AED, cuando:

  • a) E se desplaza sobre el lado AB, es decir $0 \le x \le 5$.
  • b) E se desplaza sobre el lado BC, es decir $5 \le x \le 13$.
  • c) E se desplaza sobre el lado CD, es decir $13 \le x \le 18$.

2. Expresa el área $y$ del triángulo AED, cuando E se mueve de A hasta B (ver figura 1).

3. Determina el área $y$ del triángulo AED, cuando E se mueve de B hasta C (ver figura 2).

4. Expresa el área $y$ del triángulo AED, cuando E se mueve de C hasta D (ver figura 3).

Solución

1. Al observar el movimiento que realiza el punto E en cada uno de los casos se puede concluir que:

  • a) Cuando E se mueve sobre el lado AB, el área del triángulo AED aumenta.
  • b) Cuando E se mueve sobre el lado BC, el área del triángulo se mantiene constante, pues la base es $8 \text{ cm}$ y la altura es $5 \text{ cm}$, en cualquier momento.
  • c) Cuando E se mueve sobre el lado CD, el área del triángulo disminuye hasta llegar a cero.

2. El área del triángulo AED, cuando E se mueve sobre AB, se puede calcular considerando que la base es $8 \text{ cm}$ y la altura $x$, entonces:

$y = \frac{1}{2}(8)(x) = 4x$

Es decir, $y = 4x$ para $0 \le x \le 5$.

3. El área del triángulo AED, cuando E se mueve sobre BC, en este caso la base es $8 \text{ cm}$ y la altura $5 \text{ cm}$, entonces el área es:

$y = \frac{8(5)}{2} = 20$

Es decir, $y = 20$ para $5 \le x \le 13$.

4. El área del triángulo AED, cuando E se mueve sobre CD, en este caso la base es $8 \text{ cm}$ y la altura es $(18 - x) \text{ cm}$, entonces el área es:

$y = \frac{1}{2}(8)(18 - x) = 4(18 - x) = 72 - 4x$

Es decir, $y = -4x + 72$, para $13 \le x \le 18$.
